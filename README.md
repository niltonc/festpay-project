# FestPay - Sistema de Gestão Financeira de Festas

Projeto completo em React, TypeScript e Tailwind CSS.

## Como rodar o projeto

1. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
2. Descompacte o arquivo `.zip` em uma pasta.
3. Abra o terminal na pasta descompactada e rode os comandos:

```bash
# Instalar dependências
npm install

# Rodar em ambiente de desenvolvimento local
npm run dev
```

4. Acesse o projeto no navegador (normalmente em `http://localhost:5173/`).

> Nota: O projeto já possui dados simulados (mock) configurados no `App.tsx` para que você possa testar o funcionamento (Dashboard e cálculos) imediatamente antes de conectar ao banco de dados Supabase definitivo. O esquema para o Supabase está no arquivo `supabase_schema.sql`.
